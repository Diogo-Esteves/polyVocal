# PolyVocal 🎙️

> *Speak in any language. Capture every word.*

**PolyVocal** is a fast, accurate, cross-platform speech-to-text application with built-in translation support. It works locally or in the cloud, runs on Linux, macOS, Windows — and eventually mobile — and is designed to be as simple as picking up a hairbrush and singing.

---

## Status

🚧 **Pre-development — Specification & Design phase**

## Supported Languages (planned)

- 🇬🇧 English
- 🇧🇷 Portuguese
- 🇮🇳 Hindi
- 🇨🇳 Mandarin

---

## Key Features (planned)

- 🎤 Real-time speech-to-text transcription
- 🌍 Automatic language recognition
- 🔄 Translation of transcribed text
- 🤖 Local models (e.g. Whisper) and cloud model support
- 🔁 Cross-device synchronisation
- 🖥️ Desktop: Linux, macOS, Windows
- 📱 Mobile: iOS / Android (future)

## Concept

The logo draws on the playful analogy of people using a hairbrush as a microphone — that uninhibited, expressive moment of speaking your truth. PolyVocal captures that energy and makes it real.
